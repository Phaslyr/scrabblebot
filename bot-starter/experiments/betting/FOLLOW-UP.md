# Exploratory point-forecast follow-up

The original 1,600-game guarded study made zero extra player-specific actions because the calibrated uncertainty bands were too wide to fit the existing value/cash limits. That null comparison does not test how an actionable noisy point forecast performs.

Keep the fitted predictors and public data fixed. Use the median price estimate instead of the upper interval endpoint for the response rule. Keep the same hard cash/value ceiling, four-coin maximum extension, final-tile exclusion, and useful-completion requirement. Timing holds use the median estimate with a one-coin margin. The blind and unchanged controls retain their definitions.

Run 80 fresh independent bags per bot in the midpoint empirical arena and 20 per bot in each sensitivity arena, with a new seed offset. Report this separately as an exploratory follow-up, not a predeclared confirmatory result. Do not replace the original results or deploy any policy automatically.
